OSS Singularity synthetic delivery artifact (stage 03 pilot)

This file exists so anyone can exercise the artifact-receipt verification
path with real bytes: retrieve it, hash it, and compare the digest against
the one declared in an oss-delivery-manifest that references this URL.
It carries no other meaning, authorizes nothing, and is not evidence of
any completed work.

Repeatable check: sha256sum of the retrieved bytes equals the digest the
contributor declared at delivery time. A content identifier, when one is
declared, names content plus its encoding; it is not this file checksum.
