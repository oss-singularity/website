Operating principles

The source is part of the product.

Quality lives in the choices users can see — and the safeguards they should never need to think about.

01

Open by default

Inspect it, learn from it, adapt it. The work stays available beyond any one release or platform.

02

Privacy with intent

Local-first where possible, conservative around credentials, and no hidden tracking on this website.

03

Built in the real world

Tools are shaped by actual desktop workflows, observable behavior and the unglamorous edge cases.
