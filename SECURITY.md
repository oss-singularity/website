# Security policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository when available. If that channel is unavailable, contact the project privately at `mail@oss-singularity.io`.

Do not open a public issue containing hosting credentials, API tokens, SSH keys, private paths, complete DNS exports, cPanel session URLs, cookies, unpublished infrastructure details, or screenshots containing account-specific data.

## Scope

Security fixes target the deployed website and the current `main` branch. Namecheap, cPanel, GitHub, Microsoft 365, and their underlying infrastructure remain external trust boundaries; report upstream defects to the relevant provider and notify this project privately if the integration increases the impact.
