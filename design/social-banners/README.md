# Profile banner archive

These banners are reusable artwork for LinkedIn and other external profiles.
They are archived here for maintainers and designers; the website build does
not publish them.

Each of the standard and alternate designs includes:

- `*-source.svg`: editable source artwork
- `*-outlined.svg`: artwork with outlined text
- `*.png`: exported banner image
- `*-svg-complete-v1.zip`: original bundled artwork

The website's link-preview assets remain in
[`site/assets/social/`](../../site/assets/social/). Updating a profile banner does
not change those assets or the homepage preview.

The [branding terms](../../BRANDING.md) apply to this artwork.
